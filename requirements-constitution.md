
- As branchs e commits devem seguir o padrão semantico
- sempre apos finalizar uma task deve commitar 
- sempre que terminar a implementação deve abrir o PR
- Nunca deve commitar direto na main 
- Antes de realmente finalizar a implementação e dar ela como sucesso deve executar o build e start
- Sempre criar casos de teste unitarios até atingir o coverage de 100%
- Deve usar apenas o JEST para criar os testes unitarios
- Use o MCP playwright para criar testes e2e
- Sempre deve atuar/criar a documentação no README do projeto ao finalizar a implementação
