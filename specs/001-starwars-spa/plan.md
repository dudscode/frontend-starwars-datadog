# Implementation Plan: Star Wars Explorer

**Branch**: `001-starwars-spa` | **Date**: 2026-05-30 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-starwars-spa/spec.md`

## Summary

Build a greenfield Angular 17 standalone SPA that lists Star Wars characters (client-side pagination, 10/page from a cached array of 82) and films (all 6 at once) from the **swapi.info** public REST API (`https://swapi.info/api`). The API returns flat arrays — no server-side pagination wrapper. Both datasets are fetched once and cached with `shareReplay(1)`. UI rendered with Angular Material v17. Core Web Vitals targets: LCP ≤ 2.5 s, CLS ≤ 0.1, INP ≤ 200 ms. Unit tests with JEST at 100% coverage; E2E tests with MCP Playwright.

## Technical Context

**Language/Version**: TypeScript ~5.2 (Angular 17 bundled), Node.js ≥ 18.13

**Primary Dependencies**: Angular 17, Angular Material v17, Angular CDK v17, RxJS 7.x, `jest-preset-angular@14` (JEST adapter for Angular 17), `@playwright/test` (E2E via MCP Playwright), `ts-node` (jest.config.ts parsing)

**Storage**: No local persistence. Both characters and films cached in memory via `shareReplay(1)` for the session lifetime.

**Testing**: JEST (unit, 100% coverage) + MCP Playwright (E2E, 3 user journeys)

**Target Platform**: Modern web browsers (Chrome 110+, Firefox 110+, Safari 16+, Edge 110+). SPA only — no SSR, no native mobile.

**Project Type**: Frontend web application (Single-Page Application)

**Performance Goals**: LCP ≤ 2.5 s | CLS ≤ 0.1 | INP ≤ 200 ms | Initial bundle ≤ 200 kB gzipped

**Constraints**: Standalone components only (no NgModule); OnPush change detection on all components; lazy-loaded routes via `loadComponent`; no NgRx or third-party state management; no UI libraries besides Angular Material; swapi.info returns flat arrays — no `SwapiPage<T>` pagination wrapper

**Scale/Scope**: Greenfield, single developer, 2 screens, ~10 source files, 82 characters (cached), 6 films (cached)
